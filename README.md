## Planned stack

Learn the fundamentals first, then use this stack for modern web projects:

- **Editor:** Zed
- **Front end:** Astro, React, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Node.js, Astro Actions/API routes, Zod, Better Auth
- **Database:** PostgreSQL and Drizzle ORM
- **Supporting tools:** React Hook Form, TanStack Query, Lucide, Git, GitHub, Docker, and CI/CD

## Working habits

- Build projects without relying on complete copy-along tutorials.
- Keep projects accessible, responsive, and deployed when ready.
- Use Git for small, meaningful commits.
- Update this README and the project status as work progresses.
