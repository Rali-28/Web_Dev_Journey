# html_profile_page

## Creating a profile page using basic HTML

This is the first project for mastering HTML. 
Create a simple one-page profile.

### Things to learn:

- The document structure: `<!doctype html>`, `<html>`, `<head>`, and `<body>`.
- Elements, tags, attributes, nesting, indentation, comments, and HTML entities.
- Head metadata: character set, viewport, `<title>`, and page description.
- Text: headings, paragraphs, emphasis, strong importance, links, images, line breaks, and horizontal rules.

### Things to do

- [ ] A meaningful title and meta description.
- [ ] Your name as the single `<h1>`, followed by logical heading levels.
- [ ] A short bio, profile image with useful alt text, and links to relevant sites.
- [ ] A favorites list and a small quote or contact section.
- [ ] 🍾 Project Complete! 🍾
